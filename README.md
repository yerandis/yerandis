## Selected Projects

### SGE — Employee Management System

Full-stack employee management system built with **React, TypeScript, Spring Boot, and PostgreSQL**.

The project covers employee management, authentication and authorization, role-based permissions, REST API integration, and real-time notifications.

The source repositories are kept private while the architecture, interface, and technical approach are presented here as part of my public portfolio.

#### Architecture

<img src="./assets/sge/architecture.png" alt="SGE Employee Management System architecture" width="500">

#### Technical Highlights

* **Backend:** Spring Boot REST API with layered architecture and PostgreSQL persistence.
* **Frontend:** React and TypeScript single-page application using reusable components.
* **Authentication:** JWT-based authentication integrated with Spring Security.
* **Authorization:** Role and permission-based access control for protected resources.
* **Data Access:** JPA/Hibernate with PostgreSQL.
* **Real-Time Communication:** WebSocket/STOMP-based notifications.
* **API Documentation:** OpenAPI/Swagger documentation for backend endpoints.
* **Client Integration:** Dedicated frontend service layer for communication with the REST API.
* **Application Security:** Separation of authentication, authorization, and application-level permissions.
* **UI Architecture:** Reusable components and structured frontend modules for maintainability.
